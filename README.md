# Answer.js Library

### Not just a library, it's a complete solution.

Answer.js was created to end the suffering with long and repetitive JavaScript codes. Instead of writing 10 lines to do one thing, one line with Answer.js will do it.

The idea is simple: The power of jQuery with the speed of Vanilla JS.

### Why choose Answer.js?

This library gives you full control over your website. From the smallest element on the page to server communication and storage.

- **Rocket Performance:** Less than 5kb, zero dependencies, light speed execution.
- **Cleaner Code:** Chainable System lets you write professional and clean code.
- **All in One Place:** Full control over DOM, Events, Effects, Local Storage, and Fetch API.
- **For Everyone:** Super easy if you are a beginner, and super powerful if you are a pro who wants to get work done fast.

### The Philosophy

We are not reinventing the wheel, we are making the wheel spin faster.
Answer.js is made for the developer who loves speed, simplicity, and professionalism at the same time.

If you are looking for a library to start your next project with, Answer.js is your answer.
